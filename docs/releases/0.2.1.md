# Tyler 0.2.1

**Status:** Release candidate; not published.

## Release notes

This maintenance release introduces a Python layer for the agent runtime and includes code fixes for potential bugs and issues. It adds no new user-facing features.

- Python now handles AI provider communication, conversation orchestration, and tool adapters.
- Java continues to handle the HTTP API, shared application rules, database persistence, settings, and chat history.
- The Windows application bundles the Python worker and its runtime. Installed users do not need to install Python separately.
- Code fixes address potential bugs and improve the reliability of existing functionality.
- Existing chat, food tracking, workout planning, and saved data contracts are preserved. No database reset or schema migration is required.

The legacy Java agent remains available temporarily through configuration and restart during the migration rollback window. See [rollout and recovery](../AGENT_ROLLOUT.md).

## Developer notes

The shared release version is **0.2.1**, defined in [`.mvn/maven.config`](../../.mvn/maven.config). Backend, frontend, worker, and installer artifacts must be built from this same version. The private worker protocol remains version **1**.

Source development now requires the pinned Python environment and a built worker, or an explicit development interpreter command. Follow the [setup guide](../SETUP.md) and [Python worker guide](../../agent-python/README.md).
