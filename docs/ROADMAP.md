# 1.0 production release roadmap

[Developer guide](DEVELOPMENT.md)

Tyler 1.0 is complete when all of these are done:

1. **Cloud backend.** Run the backend on AWS.
2. **Mobile apps.** Make the frontend available on iOS and Android.
3. **Report button.** Add a button that generates a report of what you have done: daily average calories, macronutrient and micronutrient facts, workouts done, and what is lacking.
4. **Body tracking.** Extend user info to track age, weight, and other body facts.
5. **Private user data.** Encrypt user data so that an admin of the AWS backend cannot see other users' information.

Items are taken one at a time, starting with the cloud backend for a single user. Multi-user support comes after that.
